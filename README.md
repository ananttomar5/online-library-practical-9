# PageTurn Online Library — Practical No. 9

A responsive multi-page online library demo made with HTML, CSS and vanilla JavaScript.

## Pages
1. Home (`index.html`)
2. Catalogue (`catalogue.html`)
3. Book Details (`book-details.html`)
4. Issue a Book (`issue-book.html`)
5. My Books (`my-books.html`)
6. New Arrivals (`new-arrivals.html`)
7. Contact (`contact.html`)

## Features
- Responsive layout for mobile, tablet and desktop
- Search books by title or author
- Filter catalogue by genre
- Book details page with URL-based book selection
- Issue-book form with validation and due-date check
- Issued-book records stored in browser LocalStorage
- New arrivals section
- Contact form validation and demo confirmation
- Mobile navigation menu

## Run locally
Open `index.html` in a browser. No build tools or server are required.

## GitHub upload
1. Sign in to GitHub and create a new public repository, e.g. `online-library-practical-9`.
2. Extract this ZIP file.
3. Upload all files and folders (keep `css` and `js` folders in place).
4. Commit the files.
5. Copy the repository URL and submit it to your teacher.

## Important notes
- This is a front-end academic demo. It does not use a real database, user authentication, or a real library service.
- Issue records are stored only in the browser/device where they are created.
- The contact form does not send email.
- Replace sample contact details with your college's actual library information.
- Add your name, class, roll number and college details to the project/report if your teacher requires them.
